Daily Report — Setup Guide

Get your automated daily report running in under 15 minutes. No technical background needed — just follow each step.

✅ Google Account
✅ Access to Google Sheets
✅ Your work email address
Progress
0 / 7
1
Make a copy of the Sheet
~1 min
✓
▼

This gives you your own personal copy of the Daily Job Report sheet. You will never edit the original.

1
Click the button below. It will open Google Sheets and ask you to make a copy.
2
A popup will appear saying "Copy document". Click the blue Make a copy button.
3
Your new Sheet will open automatically. It will be named "Copy of Daily Job Report". You can rename it to anything you like.
📋 Open Sheet Template
✅
You are done with this step once your new Sheet is open in your browser.
2
Open the Script Editor
~1 min
✓
▼

The automation code is hidden inside the Sheet. This is where you will find and edit it.

1
Inside your new Sheet, look at the top menu bar and click Extensions.
2
Click Apps Script. A new browser tab will open — this is the script editor.
3
You will see a block of code already written. Do not delete anything. Just leave it as is for now.
💡
Keep both tabs open — your Sheet tab and the Apps Script tab. You will switch between them a few times.
3
Enter your details in the script
~2 min
✓
▼

At the very top of the script you will see a block that starts with const CONFIG. This is the only part you need to edit.

Apps Script — CONFIG block
// ── CONFIGURATION — only edit this section ── const CONFIG = { smtpEmail: "your.email@company.com", // ← Your email address smtpPassword: "", toEmail: "recipient@company.com", // ← Who receives the report sheetName: "Sheet1", greeting: "Dear GM,", signoff: "Regards,", senderName: "Your Name", // ← Your name };
1
Find the line that says "recipient@company.com" — replace it with the email address that should receive the daily report.
Example: ops.manager@yourcompany.com
2
Find the line that says "Your Name" — replace it with your name. This appears at the bottom of every email.
Example: "Maria"
3
Click the 💾 Save icon at the top of the Apps Script editor, or press Ctrl + S on your keyboard.
⚠️
Keep the quotation marks " " around everything. Only change the text inside them.
4
Deploy the script as a Web App
~3 min
✓
▼

This step creates your Preview and Send links. You only do this once.

1
In the Apps Script editor, click the blue Deploy button at the top right corner.
2
A dropdown appears — click New deployment.
3
A popup opens. Click the ⚙️ gear icon next to "Select type" and choose Web app.
4
Fill in the settings exactly like the table below — do not change anything else.
SettingWhat to choose
DescriptionDaily Report
Execute asMe
Who has accessAnyone
5
Click the blue Deploy button inside the popup.
6
If a screen appears saying "Authorization required" — click Authorize access, pick your Google account, then click Allow.
7
A Web app URL will appear. It looks like:
https://script.google.com/macros/s/ABC123.../exec

Copy this URL and save it — paste it in a notepad or somewhere you can find it. You will need it in the next step.
⚠️
If you ever edit the script later, you must redeploy: Deploy → Manage deployments → Edit → New version → Deploy. The URL stays the same.
5
Paste your Web App URL into the script
~2 min
✓
▼

This connects the Preview Report button in your Sheet to the web app you just created.

1
In the Apps Script editor, scroll down until you find the function named openPreview().
2
Inside it, find the line that contains YOUR_DEPLOYMENT_ID — it looks like this:

"https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec?mode=preview"
3
Replace the entire URL with the Web App URL you copied in Step 4, then add ?mode=preview at the very end.

It should look like:
https://script.google.com/macros/s/ABC123.../exec?mode=preview
4
Save the script (Ctrl + S), then redeploy as a new version:
Deploy → Manage deployments → Edit → New version → Deploy
💡
The URL you paste must keep the quotation marks around it and must end with ?mode=preview — do not remove that part.
6
Set the automatic schedule
~2 min
✓
▼

This makes the report send itself automatically every day at 5PM. You will never have to remember to send it.

1
In the Apps Script editor, look at the left sidebar. Click the ⏰ clock icon (Triggers).
2
Click the blue + Add Trigger button at the bottom right of the screen.
3
Fill in the settings exactly as shown in the table below.
SettingWhat to choose
Choose function to runsendScheduled
Which runs at deploymentHead
Select event sourceTime-driven
Select type of time triggerDay timer
Select time of day5pm to 6pm
TimezoneYour local timezone
4
Click Save. If it asks you to authorize again — click Allow.
💡
The trigger fires sometime between 5PM and 6PM. Sundays are automatically skipped by the script — you do not need to set that up yourself.
7
Test everything
~2 min
✓
▼

Before relying on the automation, confirm each part works correctly.

1
Test the Preview button — Go back to your Sheet and click the Preview Report button. A dialog should appear with a clickable link. Click it — you should see a formatted email preview in a new tab.
2
Test the Send button — Click the Send Report Now button in the Sheet. A confirmation dialog will appear — click Yes. You should see a success message and the email should arrive in the inbox shortly.
3
Check the inbox — Open the recipient email inbox and confirm the email arrived with the correct layout and data from your Sheet.
⚠️
If something does not work, go to Apps Script → Executions (the play button icon in the left sidebar). It shows every run with full error details.
✅
If both the preview and the send test worked — your setup is complete and fully operational.

🎉 You're all set!

Your daily report automation is fully configured and running. Here's what you now have:

📊 Google Sheet as your task log
👁️ Preview Report button
📤 Send Report Now button
⏰ Auto-send at 5PM Mon–Sat
☁️ Runs entirely in Google Cloud
🚫 No software to install
